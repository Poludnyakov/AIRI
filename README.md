Валидация сгенерированных задач


Этот репозиторий содержит эксперимент по фильтрации синтетических обучающих данных для LLM-агентов. 
Проект исследует улучшение методологии self-challenging, предотвращая обучение агента на некорректно сгенерированных задачах.

Методология
В эксперименте применяется следующая архитектура:

1) Генератор YandexGPT Lite: Легковесная модель генерирует задачи по программированию (инструкция, тесты, примеры неверных решений).

2) Арбитр YandexGPT: Более мощная модель выступает в роли валидатора, оценивая задачи.

Задачи блокируются по трем критериям:

eval_mismatch — код проверки не соответствует условию задачи.

poor_coverage — примеры неверных решений не отражают реальные ошибки или являются правильными.

impossible — задача логически невыполнима.

Результаты эксперимента
На выборке из 995 задач Арбитр отбраковал 21.7 примеров.

Основной причиной блокировки в 57.9% случаях стала категория poor_coverage. Это подтверждает гипотезу о том, что небольшие модели-генераторы плохо справляются с созданием качественных краевых случаев. Без этапа LLM-валидации агент обучался бы на тривиальных или ложных негативных примерах, что привело бы к деградации его качества.

Структура репозитория
AIRI_summer.ipynb — Jupyter Notebook с кодом пайплайна (генерация, валидация, подсчет метрик).

synthetic_tasks.json — датасет из 995 сгенерированных задач.

arbiter_results.json — вердикты Арбитра с объяснением причин отбраковки каждой невалидной задачи.
